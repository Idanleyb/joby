# Decisions log

Decisions made while building, beyond what the PRD states. Add new entries at the top.

| Date | Decision | Why |
|---|---|---|
| 2026-10-29 | **The Supabase project is in Tokyo**, so Vercel functions run in Tokyo (`hnd1`) for now: the many database calls per page stay short, and only one long hop per click remains (Israel ↔ Tokyo). Founder: the move to Frankfurt is planned for the next step or the one after (in the PRD's out-of-scope list). | A Frankfurt function talking to a Tokyo database would pay ~230 ms on every call. |
| 2026-10-29 | **Speed fixes** (founder: every click took seconds). Measured locally: one page load caused ~28 extra server requests (menu and card links prefetching whole dynamic pages) and every page was rendered twice (the idle cookie set on the menu's server-action response made Next.js re-render). Fixes: links don't prefetch (`prefetch={false}`) and `app/loading.tsx` shows a skeleton at once; the idle cookie is set on page loads only, at most once a minute; the signed-in user, profile, admin role and feedback state are read once per request (React `cache`); Vercel functions run in Frankfurt (`vercel.json` `regions: ["fra1"]`) next to the Supabase project. Result locally: database/auth calls per page from 33–58 to 13–25, no extra requests per page. | Each Supabase call from a US Vercel region to Frankfurt costs ~100 ms; dozens per click added up to seconds. |
| 2026-10-29 | **Founder: "shortlist" is "מועדפים" (favorites)** in every screen (status label "במועדפים ★", button "הוספה למועדפים ★"); the database value stays `shortlisted`. The provider gets an in-app notice (`application_shortlisted`) the first time — un-marking and marking again does not notify twice. | Common Hebrew wording; tells the provider the application is being considered. |

| 2026-10-29 | **Founder: admins invite admins by email.** `/admin/admins` (admins only): name, email, role (admin or reviewer) and an editable Hebrew text (default "היי [שם], קיבלת הזמנה מ-JOBY להיות אדמין במערכת. לאישור ההזמנה היכנס/י בלינק הזה").
